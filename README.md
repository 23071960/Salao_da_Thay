# Salao_da_thay
Esse é um modelo didático de uma página web para salaõ de beleza, 
Primeiro, um cadstro de perguntas para definir autoestima e comportamento,
Segundo, uma página de agendamentos.
Novas funcionalidades serão implementadas em breve, como feedback doa gendamento e resultado de avaliação da autoestima, como conselho para cada nivel.
Outra funcionalidade é um dshboard com lista de clientes, profissionais,s erviços e edição dos agendamentos, que permite trocar de horario e alterar
preços e serviços.
a grande sacada deste modelo é que todas as validações são feitas no nivel do banco de dados.
Restrições e regras são gerenciadas diretamente pelo SUPABASE, impeduindo erros e dando uma segurança maior,
inclusive no que se refere a dados.
