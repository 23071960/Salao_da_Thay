# Salao_da_thay
Esse é um modelo didático de uma página web para salão de beleza, <span color="red">
Primeiro, um cadastro  com formulário de perguntas para definir autoestima e comportamento,</apan>
Segundo, uma página de agendamentos.
Novas funcionalidades serão implementadas em breve, como feedback do agendamento e resultado da avaliação da autoestima, com conselho para cada nivel.
Outra funcionalidade é um dashboard com lista de clientes, profissionais, serviços e edição dos agendamentos, que permite trocar de horario e alterar
preços e serviços.
A grande sacada deste modelo é que todas as validações são feitas no nivel do banco de dados.
Restrições e regras são gerenciadas diretamente pelo SUPABASE, impeduindo erros e dando uma segurança maior,
inclusive no que se refere a dados.
